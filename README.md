# CP_solutions

Algorithmic problem-solving archive | Python | LeetCode • NeetCode • CSES • Project Euler

This repository serves as a personal archive of optimal Python solutions, mathematical derivations, and algorithmic notes for competitive programming and data structure challenges. 


The repository relies on a flat, direct structure. Problems are named exclusively by their problem numbers for clean sequential sorting, while CSES problems retain their descriptive titles. 

*(Note: Since NeetCode problems are pulled directly from LeetCode, placing a solution in either the `LeetCode/` or `NeetCode/` folder ensures no duplicate files are created for the exact same problem).*
